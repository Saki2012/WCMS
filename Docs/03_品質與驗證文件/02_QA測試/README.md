# WCMS QA 測試文件

本目錄保存 WCMS QA、RD 與 AI 協作相關的初期說明文件。

## 現有文件

### `01_WCMS_QA_RD_AI協作簡報_詳細版_v0.1.pptx`

說明 WCMS 測試、問題發現、RD 修正、QA 複驗及 AI 協作的整體方向。

### `02_Issue與開單流程規範說明_v0.1.pptx`

說明 Issue 開單、PR 關聯、狀態流轉與最低紀錄要求。

### `03_WCMS_測試方向與檢查重點_v0.1.docx`

整理前台、後台、共通底層、AA、SSR／CSR、相容性及弱點掃描等測試方向，以及 AI 與人工驗證的初步分工。

## 文件狀態

目前三份文件均為 v0.1 階段資料，用於建立共同語言與測試方向。

- 尚未代表 Issue Template、PR Template、自動開單格式或回歸測項已全面落地。
- 後續應依實際 Issue、PR、複驗與 Release 經驗，逐步整理為可由 GitHub 版控及 AI 解析的 Markdown。
- 同一主題的 Markdown 為可持續維護來源時，簡報、Word 或 PDF 應標示其來源版本與產生日期。
