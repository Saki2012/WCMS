# 專案與交付文件

本目錄保存跨角色溝通、版本發布及正式交付資料，主要提供 PM、QA、客服、主管、客戶與其他非純研發情境閱讀。

## 目錄

- `01_專案簡介`：系統簡介、主管版、PM 版或客戶版說明。
- `02_專案規格書`：正式需求、規格及交付範圍文件；目前先保留目錄結構。
- `03_其他`：尚未能歸入既有分類的內部或交付文件；新增內容後應定期重新分類。

## 文件形式

本目錄可放置 Markdown、Word、Excel、PowerPoint 與 PDF，分類依據是文件用途，不是副檔名。

## 維護原則

- 技術事實應以 GitHub 程式碼及 [`01_研發與技術文件`](../01_研發與技術文件/) 為依據。
- 測試策略、AI 白箱、缺陷複驗及品質驗證資料歸入 [`03_品質與驗證文件`](../03_品質與驗證文件/)。
- 對外測試報告、驗收簡報或正式 PDF 可放在本目錄，但應標示來源版本、日期或對應驗證資料。
- 版本改善的原始資料以 [`01_開發歷程優化表.csv`](../01_研發與技術文件/03_開發歷程與版本紀錄/01_開發歷程優化表.csv) 為準；進入 `Feature/Release` 後，再依實際發布範圍產生對外 Word、Excel、PowerPoint 或 PDF。
- `03_其他/公司專案管理表.xlsx` 屬公司內部管理資料，不得直接視為 WCMS 正式規格或對外交付文件。
