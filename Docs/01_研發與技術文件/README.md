# 研發與技術文件

本目錄保存 WCMS 的技術基準與研發歷程資料，主要回答「系統如何設計、開發與維護」。

## 目錄

- [`01_系統架構`](./01_系統架構/)：整體、前端與後端架構、責任邊界及資料流。
- [`02_開發規範`](./02_開發規範/)：共通、前端、後端及 Git／PR 開發規範。
- [`03_開發歷程與版本紀錄`](./03_開發歷程與版本紀錄/)：RD／PR 階段使用的改善紀錄，以及指定時間點的收斂資料快照。

## 使用原則

- AI 進入專案或開始大型任務前，先閱讀 [`WCMS_AI資料讀取入口.md`](../WCMS_AI資料讀取入口.md)。
- 程式實作以 GitHub 指定分支的內容為準。
- 架構與開發規則變更時，應同步檢查本目錄內可能受影響的文件。
- 同一項技術規則只保留一份主要來源；其他文件以連結引用，避免複製後產生版本差異。
- 每完成一輪功能或架構收斂後，應進行一次大範圍文件檢視；合併 `Feature/Release` 前再進行發布前稽核。
- AI 白箱、QA、AA、弱點掃描與 Release 驗證資料不放在本目錄，統一歸入 [`03_品質與驗證文件`](../03_品質與驗證文件/)。
