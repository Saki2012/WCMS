## 4. HTTP Middleware Pipeline

目前 Pipeline 順序：

```text
ErrorHandlingMiddleware
→ Forwarded Headers
→ Cookie Policy
→ Security Headers
→ XSRF Protection
→ Request Localization
→ Swagger Access
→ HSTS
→ HTTPS Redirect
→ CORS
→ Response Compression
→ Authentication
→ Authorization
→ Output Cache
→ MapControllers
```

順序目的：

- 最外層先接住未處理例外。
- 先解析 Proxy 資訊。
- 在 API 前完成 Cookie、Security、XSRF 與語系。
- Authentication 先於 Authorization。
- Output Cache 在 Controller 前套用。
- 最後 MapControllers。

> [!WARNING]
> `HardeningSetup` 雖提供 Rate Limiting 註冊方法，但目前 Program 未見 `AddRateLimiting`／`UseRateLimiter`，不能宣稱已正式啟用。

## 5. FeatureDriver 核心架構

FeatureDriver 是目前後端資料型功能的主框架。

```text
Feature API
→ ApiDataController<TFormModel>
→ BizService<TFormModel>
→ Form Query / Write Operations
→ FormGraphRepoScope
→ BasicRepository<TDbModel>
→ Repository Query / Write Operations
→ ApplicationDbContext
```

核心目的：

- 以 Form Aggregate 取代舊式分散 DTO Mapping。
- 統一 Root／Detail／SubDetail 查詢與 CUD。
- 集中 Transaction、Key、Lifecycle 與 Metadata。
- 保留 Feature Biz 的 Hook 與特殊業務空間。
- 讓標準 Feature API 大幅減少重複 CRUD。

## 6. Feature 垂直切片

一個標準 Feature 通常包含：

```text
Features/<Domain>/<Feature>/
├─ Xxx_Model.cs
├─ Xxx_Biz.cs
├─ Xxx_Api.cs
├─ Xxx_Enum.cs       # 有需要才建立
└─ 其他 Feature 專用 Helper
```

例如 Announcement：

```text
Announcement_Model.cs
→ Announcement Root
→ AnnouncementDetail
→ AnnouncementDetailFile

Announcement_Biz.cs
→ 保存前驗證
→ AA Content Check
→ Required Data
→ Data Normalize

Announcement_Api.cs
→ 繼承 ApiDataController<Announcement>
→ 只增加 QueryByValidate 特殊查詢
```

這表示：

- Model 定義 Aggregate 與 Metadata。
- Biz 定義業務規則。
- API 定義 HTTP 入口與必要特殊 Endpoint。
- 標準 CRUD 不在每個 Feature 重寫。


## 9. Biz 層

### 9.1 BizService

`BizService<TFormModel>` 是 Form Aggregate 的 Biz Facade。

公開主流程：

- `BizInitCreateDatasAsync`
- `BizCreateDataAsync`
- `BizUpdateDataAsync`
- `BizDeleteDataAsync`
- `BizInvalidDataAsync`
- `BizQueryDataAsync`
- `BizQueryListAsync`
- `BizQueryTotalCounts`

### 9.2 內部 Operations

BizService 組合：

```text
FormGraphCollector
FormQueryOperations
FormWriteOperations
FormLifecycleFieldApplier
FormAggregateKeyCoordinator
BizTransactionExecutor
```

功能分工：

| Operation | 責任 |
|---|---|
| QueryOperations | Aggregate 單筆／清單／計數 |
| WriteOperations | Root／Detail／SubDetail CUD |
| GraphCollector | 收集 Aggregate Graph |
| LifecycleFieldApplier | 建立／修改人員與時間 |
| KeyCoordinator | 業務 Id、RowId、ParentRowId |
| TransactionExecutor | Transaction 與錯誤訊息 |

### 9.3 Feature Hook

Feature Biz 可覆寫：

- Before／After Create。
- Before／After Update。
- Before／After Delete。
- SaveChanges 前後。
- Query 前後。
- Prefix／Id 規則。
- 業務驗證。

標準原則：

```text
Public Biz 主流程
→ 共用 Transaction
→ Protected Virtual Hook
→ Protected／Private 業務方法
```

## 15. XSRF、CORS 與安全防護

### 15.1 XSRF

後端：

- HttpOnly Antiforgery Cookie。
- 可供 Axios 讀取的 `XSRF-TOKEN`。
- 前端回送 `X-XSRF-TOKEN`。
- 寫入來源驗證。
- CSR 遇 403 可重新取 Token 再重試。

### 15.2 CORS

- 依前端 Host 白名單。
- Allow Credentials。
- 限制 Header。
- 限制 Method。

### 15.3 Cookie

- SameSite Strict。
- Secure Always。
- Path Root。
- Token Cookie 安全設定。

### 15.4 Host／Header

- Kestrel 不輸出 Server Header。
- Header Size。
- Header Timeout。
- Forwarded Header 白名單。
- CSP／Security Header。
- HSTS／HTTPS。
